# Unemployment Analysis with Python

This project analyzes unemployment rate data using Python to understand unemployment trends, Covid-19 impact, and regional employment patterns through data visualization and exploratory data analysis (EDA).

---

## Project Objective

The main objectives of this project are:

- Analyze unemployment rate data
- Perform data cleaning and preprocessing
- Visualize unemployment trends over time
- Investigate the impact of Covid-19 on unemployment
- Identify regional and seasonal unemployment patterns
- Generate insights useful for economic and social policies

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Dataset Information

The dataset contains:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

---

## Project Workflow

### 1. Data Loading
- Imported unemployment dataset using Pandas

### 2. Data Cleaning
- Removed unnecessary spaces from column names
- Converted Date column into datetime format
- Checked for missing values

### 3. Exploratory Data Analysis (EDA)
- Calculated average unemployment rate
- Identified regions with highest unemployment
- Compared urban and rural unemployment

### 4. Data Visualization
- Unemployment trend over time
- Covid-19 unemployment analysis
- Region-wise unemployment comparison
- Correlation heatmap

### 5. Insights
- Covid-19 caused significant unemployment spikes
- Some regions experienced consistently higher unemployment
- Labour participation showed relationship with unemployment trends

---

## Visualizations Included

- Line Plot
- Bar Chart
- Heatmap
- Trend Analysis Graphs

---

## Covid-19 Impact Analysis

The project specifically analyzes unemployment trends during and after Covid-19 to understand the economic impact of the pandemic.

---

## Key Insights

- Unemployment rates increased sharply during Covid-19 lockdown periods
- Regional unemployment variations were observed
- Urban and rural areas showed different employment patterns
- Employment recovery trends appeared after pandemic restrictions eased
